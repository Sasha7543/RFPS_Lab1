## 1. Структура проекту

- `index.html` — Головна сторінка стартапу (семантичні теги, логотип, місія, завдання, таблиця засновників з `colspan`/`rowspan`, аудіо/відео, 2 зовнішні лінки, 2 якірні лінки, стилізоване речення `<span>`, `<i>`, `<b>`, `<em>`, `<u>`, модальні вікна входу/реєстрації).
- `projects.html` — Сторінка «Проєкти» (каталог із 6 проєктів з фото, країною розробки та 5 характеристиками для кожного, кнопка повернення).
- `feedback.html` — Сторінка «Зворотній зв’язок» (форма з `fieldset` «Персональна інформація» для полів 1–5, випадаючий список мети, `textarea` з обмеженнями висоти, ширини й довжини, згода на обробку, кнопки `submit`/`reset`).
- `reviews.html` — Сторінка «Відгуки про нас» (відгуки експертів, інвесторів, партнерів).
- `css/style.css` — Модерні стилі для привабливого вигляду сайту на захисті.
- `img/` — Векторні SVG-ілюстрації: логотип, фото проєктів, аватари засновників.
- `media/` — Медіа-файли: демонстраційне аудіо (pitch WAV) та відео-постер.
- `Звіт_Лабораторна_1.html` — Повний звіт, оформлений за стандартом А4 з титульним аркушем за Додатком 1 (готовий до друку або збереження у PDF).
- `ЗАХИСТ_ШПАРГАЛКА.md` — Шпаргалка до захисту та відповіді на контрольні запитання.
